TRT Australia — Care Operations (work-management layout)
========================================================

Second layout, separate from the first. Four self-contained files; no
server, no backend.

PUBLISH
  Netlify Drop:  https://app.netlify.com/drop  → drag this folder
  Then "Claim this site", make it public, and rename it.

  Keep it separate from the existing site so both links stay live.

STRUCTURE
  Overview   dashboard
  Tickets    the primary view - list/board toggle, filter by queue,
             status and priority, sortable columns, full detail page
  Client email / Internal messages   the same tickets by channel
  Schedule   automated routines and upcoming client dates
  Clients    everyone with activity, soonest obligation first

NOTE
  Every client, ticket and date is invented.
